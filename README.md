# Kazentic Desktop releases

Official installer downloads and signed update manifests for Kazentic Desktop.

The application source is maintained in a separate private repository. This repository contains distribution assets only.

The first updater-enabled release must be installed manually. Later releases can be downloaded and installed through the update icon beside the desktop navigation arrows.

Production update packages are published only after signature verification and installed upgrade validation.

Web app: https://app.kazentic.com
